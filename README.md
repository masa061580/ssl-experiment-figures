# ssl-experiment-figures (public)

Training/evaluation **figures only** for embedding into Notion experiment notes
(loss/LR/accuracy curves, ROC curves, AUC/mAP bar charts, curation funnels).

Public repository. Contains ONLY generated plots - no patient images, no
endoscopy frames, no patient identifiers, no file lists, no code.

Raw URL pattern:
`https://raw.githubusercontent.com/masa061580/ssl-experiment-figures/main/curves/<page>/<file>.png`
